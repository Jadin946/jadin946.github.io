# Research portfolio — GitHub Pages

Upload `index.md`, `_config.yml`, the `_layouts` folder, and the `assets` folder to the root of your GitHub Pages repository. Keep your existing GitHub Actions Jekyll deployment workflow (fix `push:// give me website` to `push:` if needed).

In Settings → Pages, select GitHub Actions. Push to `main`, then wait for the deployment in Actions.

Edit the text in `index.md` to personalize it. Add your email and GitHub URL under Contact. Add links to your papers, code, and CV when ready. Do not publish personal contact information you do not want public.

Your URL will typically be https://USERNAME.github.io/REPOSITORY/ (or https://USERNAME.github.io/ for a repository named USERNAME.github.io).
